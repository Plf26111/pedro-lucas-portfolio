# Pedro Lucas — Portfólio (mock de demonstração)

Site estático de exemplo, com estética inspirada na Apple (fluida, tipografia grande, seções alternando claro/escuro). Feito para servir como demonstração visual — **não é um site real do Pedro Lucas**, é um mock com conteúdo fictício (projetos, e-mail, números) para mostrar a um cliente o que dá pra fazer.

## Estrutura

```
index.html        página única
css/style.css      estilos e sistema de design
js/script.js       menu mobile, nav com blur ao rolar
```

## Como usar

Abra `index.html` direto no navegador — não precisa de build nem de servidor.

### Publicar no GitHub Pages
1. Suba os arquivos para um repositório.
2. Em **Settings → Pages**, selecione a branch e a pasta raiz (`/`).
3. O site fica disponível em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.

## Antes de usar com um cliente de verdade

Troque o conteúdo de exemplo por informações reais:
- Nome, projetos e descrições em `index.html`
- E-mail de contato (`ola@pedrolucas.dev`)
- Números da seção de estatísticas (8 anos, 40+ produtos, 15 equipes)
- Avatar "PL" — pode virar uma foto real
